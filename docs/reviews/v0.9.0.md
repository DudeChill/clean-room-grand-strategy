# Release review v0.9.0

Milestone: **the mod layer and content validation** (MOD-002, MOD-003) — the last named
engine requirement that had no implementation.

## What is new

* **Mods**: `--mods <root[,root...]>` discovers `<root>/<mod>/mod.json`, orders mods by
  dependencies then `load_after` hints (ties broken by mod name, then directory name;
  cycles rejected and named), and merges tables after the base content.
* **Override semantics**: same key replaces in place (reported), `"add": true` /
  `add_<table>` / an `add_` key prefix appends, `replace_paths` takes a table from that mod
  alone. Unknown content files, unknown entry fields, bad field types, unknown modifiers
  and colliding additions are errors, not warnings.
* **Skip-whole-mod**: a rejected mod is validated entirely before anything is merged, so a
  bad mod cannot leave half-applied content; its diagnostics go to the load report and to
  `Content::load_errors`. A normal run with a broken mod refuses to start instead of
  silently running without it.
* **Validator**: `game --validate-content [--mods ...]` runs the same load path a real run
  uses, prints the deterministic load report plus every diagnostic, audits a 1-day run and
  exits non-zero on any error. Usage errors exit 2.
* **Test pack and docs**: eight fixture roots under `tests/mods/` (clean override,
  dependency chain, `load_after` hint, append, malformed file, unknown table, unknown key,
  conflict), ten `MODPACK` tests, thirteen validator cases wired into the release gate, and
  `docs/MODDING.md` plus `tools/make_mod.py`.
* **Example mod**: `data/mods/example_mod` overrides a shipped rifle, adds an assault rifle
  and adds the technology that unlocks it — loadable, validated and used by tests.

## Known gaps (tracked, not hidden)

* **MOD-004 (MINOR)**: a mod cannot override the scenario or map yet — `load_scenario` does
  not take mod roots. Everything else in the mod layer is closed.
* **ECON-004 / AI-014 (MINOR)**: the AI piles up gear the army cannot use; factory
  assignments follow pre-loss control counts and self-heal a tick later.
* Remaining MAJORs: **INT-001** intelligence, **MP-001** multiplayer transport.
