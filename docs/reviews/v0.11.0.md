# Release review v0.11.0

Milestone: **multiplayer transport** (MP-001, the last MAJOR) — deterministic lockstep with
desync tooling, so two machines can play the same campaign and prove they stayed identical.

## What is new

* **Lockstep session** (`src/net/lockstep.{h,cpp}`): peers exchange only commands. Seats are
  ordered deterministically (ascending seat, then tag, then country), each seat's
  submissions for a tick are coalesced, and a tick opens only when **every** seat has
  submitted — including an explicit "I have nothing to say" (`submit_empty`). A lagging
  seat stalls the session; it never skips.
* **Framing**: length-prefixed little-endian records reusing the save's command serializer,
  so command logs and network payloads are the same bytes. Truncated, concatenated,
  malformed and oversized records are rejected or buffered, never crashing.
* **Desync tooling**: peers exchange `world_hash` plus the per-subsystem report every 24
  ticks. A mismatch halts the session and prints a report naming the tick, both hashes, the
  **first differing subsystem**, and that tick's ordered command list.
* **Transport** (`src/net/transport.{h,cpp}`, dependency-free POSIX sockets) and CLI:
  `--host --port N --players K --player TAG` and `--join HOST:PORT --player TAG`, with a
  roster handshake that refuses a `--players` mismatch, a peer seated in a country the local
  scenario does not have, or a duplicate seat.
* **Peer loss is explicit**: a peer that leaves stops the other side with
  `session failed: peer seat 1 (KOR) left the session` and a non-zero exit — a vanished peer
  is never silently treated as "submitted nothing".
* **One hash fix that made this possible**: `player_country` (which country a human holds)
  is per-peer view state; it now lives only in the save header, not in the hashed Ai
  subsystem (save version 10). `ai_controlled` stays hashed, and a session sets every seated
  country to human on every peer, so both sides agree.

## Known gaps (tracked, not hidden)

* Multiplayer residuals, documented in `docs/MULTIPLAYER.md`: no matchmaking, no NAT
  traversal, no reconnect, no spectators, no in-session chat.
* MINORs: **MOD-004** (mods cannot override the scenario/map), **ECON-004** (the AI piles up
  unsupported gear), **AI-014** (factory assignments follow pre-loss control counts).
* Known differences are listed in `docs/KNOWN_DIFFERENCES.md` (no party-support vector, so
  ideology operations apply as war support; counter-intelligence reads agency upgrades only).
